# Underwater Drone Hide-and-Seek

Proyek simulasi hide-and-seek menggunakan underwater drone (AUV/ROV) dengan ROS 2 dan Gazebo.

## Struktur Proyek
## GOKIL LU NDRONG

- **simulation/** - Simulasi lingkungan bawah air (Gazebo)
- **navigation/** - Navigasi, path planning, dan obstacle avoidance
- **perception/** - Deteksi objek, tracking, dan image processing
- **integration/** - Launch files dan konfigurasi integrasi
- **tests/** - Unit tests untuk semua modul
- **docs/** - Dokumentasi proyek
